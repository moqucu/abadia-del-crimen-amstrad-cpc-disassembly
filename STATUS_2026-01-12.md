## Technical Details

### Block 0x01 Bytecode Analysis
```
Address: 0x1973
Tiles: [0x28, 0x09, 0x29] → [bottom, middle, top]
Bytecode: F7 71 01 6E 6E 84 71 EF FD FC F9 61 FE F9 62 FA F9 63 FB F5 F4 FA FF

Execution flow:
1. Setup registers with tile IDs
2. Loop Param2 times (outer loop)
3. Push position
4. Paint bottom tile, DecY
5. Loop Param1 times (inner loop)
6. Paint middle tile, DecY
7. Paint top tile
8. Pop position
9. IncX, DecY (move diagonally)
```

### Key Findings
- Tiles use correct file paths: `src/abadia/resources/tiles/palette_day/tile_XXX_0xYY.png`
- Coordinate system: DecY moves up visually (decreasing Y value)
- Block parameters: param1=x_length, param2=y_length from room data
- Iteration safety limit: 50,000 opcodes per block
