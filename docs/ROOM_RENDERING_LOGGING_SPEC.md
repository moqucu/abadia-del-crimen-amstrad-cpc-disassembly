# Room Rendering Logging Specification

This document defines the exact format of the logging output generated by the Python room rendering script. This specification is intended to be used by other implementations (e.g., JavaScript) to produce identical logs for automated comparison and debugging.

## Log File Location and Naming

*   **Directory:** Same directory as the rendered PNG images.
*   **Filename:** Matches the image filename but with a `.log` extension.
    *   Example: `room_1_day.log` corresponds to `room_1_day.png`.
*   **Naming Convention:** `room_{JS_ID}_{PALETTE}.log`
    *   `JS_ID`: 1-based room index (Python Room ID + 1).
    *   `PALETTE`: `day` or `night`.

## Log File Format

The log file is a plain text file containing three main sections separated by delimiter lines.

### Header
Contains metadata about the rendered room.

**Format:**
```text
Room Index: {PYTHON_ID} (JS ID: {JS_ID}) - Palette: {PALETTE}
================================================================================
```

### 1. SECTION 1: BLOCK MANIFEST (Input)
Records the sequence of blocks processed from the room definition. This trace logs the input parameters passed to the block script.

**Section Header:**
```text
SECTION 1: BLOCK MANIFEST
Summary: {RENDERED_COUNT} rendered, {SKIPPED_COUNT} skipped
Unique Block Types: {HEX_BLOCK_ID_LIST}
--------------------------------------------------------------------------------
```
*   `HEX_BLOCK_ID_LIST`: Comma-separated list of unique **Raw Block IDs** (e.g., `0x02, 0x1E`). These are `ScriptID * 2`.

**Line Format:**
```text
  Block #{INDEX}: ID 0x{BLOCK_ID} | Pos: ({X},{Y}) | Size: ({W},{H}) | H: {HEIGHT} [{STATUS}]
```
*   `INDEX`: 0-padded, 2-digit index of the block in the room's list (e.g., `00`, `01`).
*   `BLOCK_ID`: 2-digit Hexadecimal **Raw Block ID** (e.g., `1E`).
*   `Pos`: `(X, Y)` coordinates in the room grid (0-31 range).
*   `Size`: `(Width, Height)` parameters (actually Param1/Param2) passed to the script.
*   `H`: The `height` parameter (extra byte) passed to the script. Defaults to `255` if not present in data.
*   `STATUS`: `OK` if rendered successfully, `ERROR` otherwise.

**Section Footer:**
```text
--------------------------------------------------------------------------------
```

### 2. SECTION 2: CHRONOLOGICAL DRAW EVENTS (Interpreter Output)
Records every single `DRAWTILE` command issued by the interpreter, in the exact order of execution. This section exposes the internal register state before any buffering or sorting occurs.

**Section Header:**
```text
SECTION 2: CHRONOLOGICAL DRAW EVENTS (Interpreter Output)
```

**Line Format:**
```text
  Event: Block #{PRIO:02d} -> DrawTile({TILE_ID}) @ ({X},{Y}) | RawRegs: ({RAW_DX}, {RAW_DY})
```
*   `PRIO`: The Block Index (same as `INDEX` in Manifest).
*   `TILE_ID`: Decimal ID of the tile being drawn.
*   `X`, `Y`: The current `l` and `h` coordinates of the interpreter cursor.
*   `RAW_DX`, `RAW_DY`: The raw values of Register 16 (`DEPTHX`) and Register 17 (`DEPTHY`) passed to the graphics engine.

**Section Footer:**
```text
--------------------------------------------------------------------------------
```

### 3. SECTION 3: FINAL RENDER LIST (Graphics Output)
Records the flattened, sorted list of tiles exactly as they are rasterized to the screen (The Painter's Algorithm order). This reflects the state of the Z-Buffer after all scripts have finished.

**Section Header:**
```text
SECTION 3: FINAL RENDER LIST (Graphics Output)
```

**Line Format:**
```text
  Order #{IDX:03d} | Depth: {DEPTH:>3} | Prio: {PRIO:02d} | Tile: {TILE_ID:<3} | Screen: ({SCR_X}, {SCR_Y})
```
*   `IDX`: 0-padded, 3-digit sort index (000 = drawn first/background).
*   `DEPTH`: Calculated Z-depth value used for sorting. Right-aligned, width 3.
    *   Formula: `DepthX + DepthY - 16`.
*   `PRIO`: The Block Index that generated this tile. Used as a secondary sort key.
*   `TILE_ID`: Decimal ID of the tile image. Left-aligned, width 3.
*   `SCR_X`, `SCR_Y`: Final pixel coordinates on the output image (320x200 space).
    *   `SCR_X = BufferX * 16 + 32`
    *   `SCR_Y = BufferY * 8`

## Example Output

```text
Room Index: 0 (JS ID: 1) - Palette: day
================================================================================
SECTION 1: BLOCK MANIFEST
Summary: 33 rendered, 0 skipped
Unique Block Types: 0x02, 0x04, 0x06, 0x08, 0x0C, 0x10, 0x18, 0x1C, 0x1E
--------------------------------------------------------------------------------
  Block #00: ID 0x1E | Pos: (7,14) | Size: (1,0) | H: 255 [OK]
  Block #01: ID 0x1C | Pos: (15,17) | Size: (3,7) | H: 255 [OK]
--------------------------------------------------------------------------------
SECTION 2: CHRONOLOGICAL DRAW EVENTS (Interpreter Output)
  Event: Block #00 -> DrawTile(5) @ (7,14) | RawRegs: (0, 0)
  Event: Block #00 -> DrawTile(5) @ (7,13) | RawRegs: (0, 0)
  Event: Block #01 -> DrawTile(1) @ (15,17) | RawRegs: (0, 0)
--------------------------------------------------------------------------------
SECTION 3: FINAL RENDER LIST (Graphics Output)
  Order #000 | Depth: -16 | Prio: 00 | Tile: 5   | Screen: (32, 40)
  Order #001 | Depth: -16 | Prio: 00 | Tile: 5   | Screen: (32, 32)
  Order #002 | Depth: -16 | Prio: 01 | Tile: 1   | Screen: (48, 8)
  ...
  Order #315 | Depth:  46 | Prio: 31 | Tile: 207 | Screen: (32, 56)
```
