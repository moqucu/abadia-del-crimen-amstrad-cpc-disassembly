#### Assembly Code Analysis (DEFINITIVE)
- Examined original disassembled code at address **0x1AF1**
- **CRITICAL FINDING**: Blocks 0x0B and 0x0C share **identical drawing code**
  - Block 0x0B: Address 0x1AEF → falls through to 0x1AF1
  - Block 0x0C: Address 0x1B28 → calls FlipX(), then jumps to 0x1AF1
  - Only difference is Block 0x0C mirrors the rendering with FlipX()

#### Assembly Code Structure (0x1AF1)
```assembly
// Staircase drawing routine
F7 70 02 6D 6D 84 70   // depth x = depth x - (param1*2 + 2)
F7 71 01 6E 6E 84 71   // depth y = depth y - (param2*2 + 1)

EF                      // IncParam2()
FD                      // while (param2 > 0){
  FC FC                 //   pushTilePos() twice
  F9 61 80 65           //   paintTile(61, decY_and_paint, 65)
  FB F3                 //   popTilePos(), decTilePosX()

  FE                    //   while (param1 > 0){
    FC                  //     pushTilePos()
    F9 62 80 66 80 67   //     paintTile(62, decY_paint, 66, decY_paint, 67)
    FB F4 F3            //     popTilePos(), decTilePosY(), decTilePosX()
  FA                    //   }

  F9 63 80 68 80 69     //   paintTile(63, decY_paint, 68, decY_paint, 69)
  FB F4 F4 F5           //   popTilePos(), decY×2, incTilePosX()
FA                      // }

F3 F0                   // decTilePosX(), IncParam1()
FE                      // while (param1 > 0){
  F9 64                 //   paintTile(64, decrementY)
  F3                    //   decTilePosX()
FA                      // }
```

## Key Technical Insights

### Block Tile Loading Pattern
- Consistent across all blocks examined
- Blocks load 12 tiles into registers (tile_data array)
- Typically only 3-8 tiles actually painted
- Other tiles loaded by shared subroutines
- **Not a bug** - this is the game's design pattern

### Block Parameter Usage
- **param1**: Often controls width/horizontal extent
- **param2**: Often controls height/vertical extent or repetition count
- Specific meaning varies by block type
- Some blocks use params to control architectural features (window height, railing height, etc.)

### Assembly Code Sharing
- Multiple blocks share the same drawing subroutines
- Example: Blocks 0x0B and 0x0C use identical code at 0x1AF1
- Differentiation through FlipX() and different tile sets
- Code reuse keeps game binary size manageable
