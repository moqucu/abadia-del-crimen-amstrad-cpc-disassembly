```assembly
4E59: cp   $0B        ; compare tile with 0x0B (11)
4E5E: jr   c,$4E92    ; if tile < 11, jump to simple LDI path
4E65: bit  7,(ix+$02) ; check bit 7 of tile number
```

**Three tile categories**:

3. Tiles 128-255: Lookup tables at `0x9F00/0xA000`

### 5. Remaining 23 Differing Scripts

**Scripts**: 17, 18, 19, 20, 29, 38, 42, 47, 48, 50, 52, 57, 58, 67, 72, 74, 77, 83, 84, 85, 86, 87, 91

**Identified Issues** (analysis started, not yet fixed):

#### Issue 1: DRAWTILE Sequence Parsing (SCRIPT17, 18)
- DRAWTILE with multiple tiles and `0x80` control bytes
- Our parser exits sequence too early
- Interprets remaining bytes as opcodes (POP, Unknown)
- **Root cause**: Need to handle `0x80` control byte in paint_tile loop properly

#### Issue 2: Missing Address Mappings (SCRIPT19, 20, 47)
- `$1D59` should map to SCRIPT96
- `$172F` should map to SCRIPT46 offset
- Need to add more subroutine addresses

#### Issue 3: Block Data/Offset Issue (SCRIPT29)
- First opcode differs: `INC X` vs `FLIP X`
- Entire structure misaligned
- Possibly wrong start address in block library

#### Issue 4: Expression Parsing (SCRIPT38)
- `PARAM2 - PARAM1` vs `-( PARAM2 ) + PARAM1`
- These are algebraically different (negatives of each other)
- Expression parsing order issue

#### Issue 5: Tile Register Offset (SCRIPT42, 77)
- `DRAWTILE T2` vs `DRAWTILE T0`
- Tile register indices offset by 2
- Possibly tile_data array issue in block library
